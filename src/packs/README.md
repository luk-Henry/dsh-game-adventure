# 内容包（src/packs）

门后的**文案**与**世界**全在这里，代码只剩「怎么讲」。加一个世界不用改 client.js
的逻辑，加一个目录就行。

```
src/packs/
  index.js              注册表 + 装载器（applyPack / listPacks / setPack / isUnlocked）
  reserved.js           三套**预留**的名字（规则怪谈 / 宫斗心计 / 谍战潜伏）：只有名字与一句「它的核」（点一下才摊开），还没有内容
  rules.js              读「世界的规矩」的机器（dangerOf / outcomeOf / worldBucket / momentOf / choiceOf / directionOf / fateOf / fightOf / forkOf / resultOf / checkRules / checkMoments / checkChoices / checkDirections / checkFates / checkMarks / checkFights / checkForks）
  rules.md              规矩那一层怎么设计、怎么证明没抄错、换世界要改哪几行
  adventure/index.js    世界包：冒险者的事务所（句子，以及一天的头尾与那顿饭 `dayFrame`、开头那一段序曲 `origin`、战斗 `fights`）
  adventure/world.js    那个世界的地理：取景框、七处地点、默认主题、一句话、封面一个字
  adventure/moments.js  高光事件（2026-10-08 加的，2026-10-09 加厚）：八件事的条件、经过、代价与收束；**里面那两条路 2026-10-10 起退成叙述**（不再摆选项，`choice`/`cost` 留着备用，形状仍归 R18 管）
  adventure/clash.js    交锋（2026-10-08 加的）：26 个场景各两条「接住」与两条「代价」
  adventure/directions.js 方向与比例（2026-10-08 加的）：四档方向的上限、危险系数与抬头
  adventure/fate.js     归宿（2026-10-08 加的）：九件「这一年他是怎么过来的」的条件与说法
  adventure/marks.js    当天的痕迹（2026-10-09 加的）：六样痕迹各三池，132 句
  adventure/fights.js   战斗（2026-10-10 加的）：五种对手、三档、四到七拍，以及日卷末尾那句战报，141 句
```

## 四层：哪些能卖、哪些永远不卖

| 层 | 是什么 | 卖不卖 |
|---|---|---|
| **事实层** | `~/.dsh/gameflow/records.json` 与 `ticks`：动作、时长、失败、文件名 | **永远不卖**，也不许因为付费变准变全 |
| **讲述层** | `actionLines`、`words`、`scenes`、`shards`、`moments`（连里面的岔口、代价与痕迹）、`marks`、`dayFrame`、`fights`、`journey`、`forks`、`clash`（2026-10-10 起不接线，只当备用）、`origin`、`directions`、`fate`（换说法、换词表、换事件、换一天的头尾与那顿饭、换一场仗的对手与拍子、换册子上的路线与他今天打算干什么、换他遇上的那三件命运与两条路、换交锋那两拍、换开头那一段序曲、换方向与比例、换年卷末尾那一段收束、换当天留下的痕迹） | 最便宜的一层，可以低价/引流 |
| **世界层** | 地理、`scenes` 里的世界、`cast`、`worldLines`、`props` | **最值钱**，一次性卖的主体 |
| **规矩层** | `rules`：什么算危险、什么算收获、外头多容易出事 | 故事包的性格所在（只改门槛，不改事实） |
| **收尾层** | `more`/`paid`/`hurt`/`again`、`life` | 最易做歪，跟着世界走 |

判据一句话：**卖"谁来讲"和"这是个什么世界"，绝不卖"事实"。**

## 包接口

一个包就是一个 `export const <id> = { ... }`（纯数据，不许有函数）。

| 字段 | 类型 | 谁用 | 说明 |
|---|---|---|---|
| `id` `name` `kind` `free` `voice` `label` | 字符串/布尔 | 装载器、界面 | `kind` 是 `world` 或 `voice`；`voice` 是它在 `VOICES`/`SCENES`/`SHARDS` 里的键 |
| `tagline` `cover` | 字符串 | 界面 | `tagline` 是「故事风格」那个名字与清单里每一项**悬停时浮出来的那一句话**（也是门后那句「某某还没解锁」的料）——**它得配得上那一套的质地**，写法见下面「说法清单」一节；**预留的包也用它**（只有名字的那三套，这一句**点一下才摊开**在名字底下）；`cover` 是原来书脊上那**一个字**，入口搬走之后界面暂时不画它（留着给以后）。句子一律不进 `listPacks()` |
| `theme` | 主题 id | 界面 | 这个世界默认用哪套材料（`THEMES` 的键）。只给 id：换世界不该顺带重写一套配色。调用方显式指定了主题时以调用方为准 |
| `map` `places` | `{ view, svg, css }` / `{ id: { x, y, door, name, wild? } }` | 世界层 | **要么都给要么都不给**（校验器 R11）：框是照着一段画好的 SVG 裁的，坐标是照着同一张图钉的。**都不给就退回默认世界那一套地理**——薄世界包可以只带句子。`wild: true` 是**野地**（2026-10-08 加的，第三十九版）：那儿没有房子，所以 `x/y` 就是那一点、`door` 与它重合；它也是「这个场景的人在城外」的判据——熟人串场（`CAST`）与「外头多容易出事」（`OUT_KEYS`）都看它，不看 `place === null` |
| `actionLines` | `{ 动作: 句子 }` | 讲述层 | 六个动作各一句兜底（**不是池子**，一句就够） |
| `words` | `{ 动作: [词] }` | 讲述层 | 左栏标签翻成他那边的说法；另有 `深夜`/`很晚了`/`坐了很久`/`一小会儿` 四个按时间取的键 |
| `sharedLines` | `{ 情形: 句子 }` | 世界层 | 说法中立的情形句（away/asleep/lateness/fleeting/longSit/idle/quiet/satLong） |
| `homeLines` | `[句子]` | 世界层 | 他人在落脚处时那句 |
| `scenes` | `{ 动作: [场景] }` | **只有世界包给** | 场景＝`{ key, w, lead: [半句], tail: [半句], place?: null }`，`place: null` 表示**户外的活**（地图上不钉记号）。
**挑哪一件事永远按世界包挑**，跟当前说法无关——所以换说法不会把记号挪走，也不会出现「记号在地图外面、句子却说他在案前」。讲述者包写了这个字段也没人读。 |
| `shards` | `{ 场景 key: { w, lead?, tail?, more, paid, hurt, again } }` | 世界层给底子，**讲述者包按场景键覆盖** | 四档结局＋承接句，键必须与 `scenes` 里的 `key` 对上。讲述者包只写自己那套说法（`w` 是这件事在它嘴里的名字、`lead`/`tail` 是它自己的半句），没写的场景键就退回动作级、再退回 `actionLines` |
| `origin` | `{ name, lines: [句子] }` | **讲述层**（跟句子一样归说法管，薄包退回世界那一份） | **序曲**（2026-10-08 加的，第五十一版）：故事开头那一段固定的开场，**六句按顺序说**（不从池里挑）；`name` 是他的名字（`塔里恩`），单独一格——第 ⑤ 件「归宿」用它（每一卷年卷末尾那句收束也带一次）。**挂在最老的那一行上**（不是第 0 天那个日卷：那一行迟早被折叠梯子折掉），落在右栏**主句上面**、底下压一条虚线；**名字全篇只出现两次**（这一段的第一句、年卷末尾那句收束，其余句子照旧一律用「他」）。起点不另存日期（＝最早那条记录所在的那一天）。校验是 **R15** |
| `clash` | `{ 场景 key: { hold: [句子], cost: [句子] } }` | **讲述层**（跟句子一样归说法管，薄包退回世界那一份） | **交锋**（2026-10-08 加的，第五十版）——**2026-10-10 起不再接线**（用户 m14810 第 6 条「旧的留作备用，修修改改用」）：面板上已经换成下面 `fights` 那一层，`CLASHES` 与 `clashOf` 一个字没删、`verify-packs` 照旧比它。撞得厉害的那一天，挨打那句下面接两拍——`hold` 是**接住**（他反手怎么处理）、`cost` 是**代价**（这一下留下什么）。**键必须与 `shards` 一一对应**，所以对手与场地必定合得上（挑到「卷内爬出虫」就不可能接一句「桥上」的代价）；**有 `shards` 的场景就必须有交锋**。只在**日卷与老式整张卡**上挂（五分钟的格不挂）、**有高光事件就不叠**（一天只讲一件大事）、**不设 `fails` 阈值**（挂在那一行已经由 `outcomeOf` 落好的那一档上）。校验是 **R14** |
| `moments` | `[{ id, weight, when, steps, choice?, close }]` | **讲述层**（跟句子一样归说法管，薄包退回世界那一份） | **高光事件**（2026-10-08 加的，第四十四版）：一件事＝`when` 条件 ＋ 4–5 句 `steps` 经过 ＋ 1 句 `close` 收束。`when` 是**项语言**的数组，**每一项都中**才算中；`momentOf` 在 `dangerOf` 那套项名之外多认三个：`hours`（钟点区间，`{ when: 'hours', in: [[22,24],[0,5]] }`）、`places` / `scenes`（那天走过哪儿，`{ when: 'scenes', has: ['mine'] }`）。一天**最多一件**，按列表顺序取第一件。落在**日卷那一行下面**、接着他手上那句话往下说，不点不开窗；同一份记录看两眼一个字都不变。校验是 **R12**。<br>**岔口**（2026-10-08 加的，第五十三版，即第 ④ 件「选择点」）：`choice: { roads: [{ id, label, when?, lines }] }`，**正好两条路**，前一条带条件、**最后一条不带**（谁都没轮到就归它）；两条都是**外头的路**。判据只读那天真有的信号（`minutes` / `fails` / `deliverables`），不读场景。读它的是第六台机器 `choiceOf(facts, choice, ctx)`；走的那条**封在这一件里**（`entry.choice` 是推出来的字段，不写回记录），渲染时接在 `steps` 之后、`close` 之前，同一台阶、不缩进、不画记号。校验同属 **R12**。<br>**2026-10-09 加厚（第八十版，用户第 2 条「命运抉择」）**：每一件多一个 **`weight`**（1–3 的份量），**摆了岔口的事件必须 ≥ 2**；每条路多两样——**`cost`**（一句写明代价的完整话，不许空、不许零代价）与 **`marks`**（1–2 样痕迹，取自六个：伤 `wound` / 账 `debt` / 名声 `fame` / 得着 `gain` / 知道 `lore` / 丢掉 `loss`）。事件从**四件变八件**（夜袭 3 / 矿洞塌方 3 / 桥头埋伏 3 / 通宵 2 / 帮手来了 2 / 走岔 2 / 回头找 2 / 交割日 2，**顺序即优先级**），界面上这一处叫**「命运抉择」**、代价**挑之前就摆在胶囊下面**。校验是 **R18**（`checkChoices`：份量够重 / 两条路都要有代价 / 两条不对称 / 每条路至少留一样痕迹）。<br>**2026-10-10（第八十六版）：这一层退成叙述。** 用户 m16528 第 2 条「代价是不可知的，选都还没选，结果却已经知道了，那么命运就成了既定」——说的就是「代价挑之前就摆在胶囊下面」这件事。于是**事件层不再摆选项**：渲染只剩 `steps` ＋ `close`，摆选项整个搬到 `forks` 那一层。**内容一个字节没删**（`choice`/`cost` 留着备用，用户 m14810 第 6 条「旧的留作备用，修修改改用」），`choiceOf` 与 R18 照旧管它的形状；`gf-choice-*` 这些类名从此只属于命运那一层 |

## 一天的头尾与那顿饭（2026-10-08 加的，第四十九版）

用户看过中魔那一版之后回的第二条：「**C1。角色时间要和用户的时间对得上，比如早上、中午、晚上都得吃饭，但有可能因为什么事而耽误。**」——三阶段方案里 C 有两条路（C1 一天有头有尾 / C2 一天一条线），他挑了 C1；同一批里他还点了第 1 条「剑与魔法可以写，不过多不泛滥」，那八句也落在这一版。

**一件事的形状**：一天＝一句定场（`open`，按第一格的钟点）＋ 中间原来那些行 ＋ 一句收尾（`close`，按最后一格的钟点）；那顿饭（`meal`）归**蓝框**，跟别的日子句排在一起。**今天那半截卷不说收尾**——一天还没过完，没有「这一天到这儿」可言。

| 落在哪 | 数量 | 挑法 |
|---|---|---|
| `open` | 6 档 × 3 句 | 第一格的钟点：dawn 0–6 / morning 6–11 / noon 11–14 / afternoon 14–18 / evening 18–22 / night 22–24 |
| `close` | 6 档 × 3 句 | 最后一格的钟点；**开工在 18 点之后、收在 6 点之前算 `night`**（真存档里 10 月 5 日那卷 15:20 干到 00:00，收尾是「快天亮时他把东西归拢好，才算完。」） |
| `meal` | 3 顿 × 3 句 ＋ 3 顿「拖过点」× 3 句 | 早饭 8–10 / 午饭 11–14 / 晚饭 17–20（早饭从 8 点起，是为了不跟生活层 5–8 的「清早」那一桶打架） |

**五条要点**：

1. **只读真实钟点**：`dayFrameOf(entry, partial)` 从记录自己的 `startedAt`/`endedAt` 取小时，不编；`mealOf(entry, prev)` 把这一段从开工到收工按半小时走一遍，看它盖住了哪几顿。
2. **「耽误」的判据是两样**：落在窗口**最后一小时**，或者一口气坐了 **150 分钟以上**（`mins >= 150`）。被耽误的那一顿优先报，否则报最后盖住的那一顿。
3. **一格只说一次**：上一格也在这顿饭的窗口里，这一格就不说（`mealOf` 里拿 `prev` 判）。
4. **呈现**：定场句在主句**上面**（`.gf-day-open`，透明度 0.82）、收尾句在整段**最下面**（`.gf-day-close`，0.8）；不换字号、不缩进、不另起一层——它们是这一天的框，不是新的一层。**只有日卷那一档有**。
5. **这一组只住包里**：跟 `MOMENTS` 一样，`src/client.js` 里只有一份空壳 `export let DAY_FRAME = { open: {}, close: {}, meal: {} }`，句子不抄第二份（`applyPack` 里 `target.DAY_FRAME = words('dayFrame')`）。所以**加句只改一个文件**——跟 `worldLines` 那批不一样。

**顺手修掉的一个真缺陷**：`lateOf` 原写 `at.get(name) >= win[1] - 1`——`MEALS` 的三元组是 `[名字, 起点, 终点]`，`win[1]` 是**起点**（早饭 8 / 午饭 11 / 晚饭 17），于是三顿一律算「耽误」。改成 `win[2] - 1`（窗口最后一小时）。

**校验**：`scripts/packs.mjs` 的 **R13**——三样都在、六档钟点与六顿饭的名字逐个对、多出来的键报「不认识的钟点 / 饭」；`dayFrame` 整棵也在 R1（阿拉伯数字）/ R2（现代词）/ R8（！？与引号）的扫描范围里，`meal` 那三桶还进 R5（蓝框不许出现行当词），`open`/`close` 进 R6（活计句不许出现起居词）。

## 方向与比例（2026-10-08 加的，第五十二版）

用户 m07234 第 2 条原话：「**比例需要调整，如何才是合理的比例，刚才只是我写的一个例子，请你思考一个方案**」——他举的例子是「涉险 50 / 攒盘缠 10 / 寻吃食 10 / 过日子 30」。这一版落 **③（方向 + 比例，方案 A）**。

**比例是上限，不是配额。** 配额是「今天该演一场涉险了」，那会逼着机器替日子编事——真没出事的那天也得硬塞一场。上限只管**不许过多**：判的时候看**这一天之前所有日子**里这一档已经占了多少，加上这一天会不会超过 `cap`。于是**历史永不被重写**（明天多一条记录，不会改动昨天的方向），也**不会硬凑满**（真没事的那天不写涉险）。四档上限加起来是 105，**这是有意的**。

| id | label | cap | bias | 什么时候轮到它 |
|---|---|---|---|---|
| `risk` | 涉险 | 50 | +7 | 那天真出过事（`fails ≥ 1`） |
| `coin` | 攒盘缠 | 20 | 0 | 那天真交出去东西（`deliverables ≥ 1`） |
| `food` | 寻吃食 | 20 | 0 | 那天有过 0–8 或 19–24 的钟点 |
| `hearth` | 过日子 | 100 | −7 | 兜底（`fallback: true`，不看条件） |

**顺序即优先级**：前面都不轮到就归兜底，所以过日子拿到的是「剩下的」（真素材下通常三到五成，正合他写的「过日子 30」）。涉险给一半，是因为他 m06647 那句「我几乎没看到过任何战斗」——可一半已经是「三天两头」，再多就不是日子，是一部连着打的戏了。

**方向管三件事**：

1. **日卷那一行的抬头**：定场句下面一句（`gf-direction`，比定场句再压暗一档）。只有**日卷**那一档有——五分钟的格不挂（那是刻度，不是一天的讲法），周/月/年卷也不挂。
2. **危险系数动一档**：`dangerOf` 在世界那几项之上加减 `bias`（世界封顶 55 仍不变，加上方向最多 62——**不是必然挨打**）。
3. **「外头」那层按方向加权**：`risk → encounter +18`、`coin → news +12`、`food → visitor +12`、`hearth → quiet +12`，四项都插在 `{ when: 'always', bucket: 'quiet' }`（兜底）**之前**。这一条顺带兑现了「战斗要多一点」——但它要那天真撞过墙才算涉险。

**只读**：算完挂在 `entry.direction` 上（`directionsFor(entries)` 在 `renderTimeline` 里跑一遍，按 `startOfDay` 把记录收成「一天一份事实」再逐天判），**不写回 `records.json`**，跟折叠一样是呈现。同一份记录看两眼，抬头一个字都不变。

**一处自己撞出来的毛病**：上限第一版算的是 `used / total`，四天夹具落成**三天涉险**——因为「已经占了多少」里**没算上正在判的这一天**，上限会一路漂到七成五。改成 `(used + 1) / total` 之后是 `hearth / risk / hearth / risk`（涉险正好一半）。**恰好卡在上限时放行**是有意的：比例停在上限，多一天都不给。

**校验**：`scripts/packs.mjs` 的 **R16**——四样都在、`cap` 在 1–100、兜底正好一个且 `cap 100` 且不许带条件、非兜底必须有条件、`lines` 至少三句；`directions[*].lines` 进 `SENTENCES`（完整句该带句号）与池内重复检查。第五台机器 `directionOf(facts, directions, { before })` 回答「那一天朝哪边走」；项语言多认一个 `{ when: 'direction', is: ['risk'], add: 7 }`（**只在世界层用**——`entry.direction` 是按天算的，单条记录永远不中）。

## 归宿（2026-10-08 加的，第五十四版）

「全做。」五项的最后一件，原话是「**归宿（年卷末尾一句收束，由聚合事实＋方向＋选择分布算出来）**」。到这一版，五项全部落完。

**挂在每一卷年卷上，渲染在那一行最下面。** 一年一份账。年卷那一档本来只有左栏的标签、主句，以及（若它正好是最老那一行）开头那一段序曲——世界句、生活句、高光事件、交锋在年卷上都不出现（`worldOk` 只到周卷、`lifeOk` 只到日卷、事件与交锋只认日卷），所以年卷那一行的末尾**正好空着**，那一段就落在那里。

**那一年的账得重跑一遍同一台挑句机器。** `rollUnit` 的返回多带一个 `list`（那一年的全部内部格），`fatesFor` 拿它跑一遍 `sequenceOfUnits`，按天分开、每天收成一天、`dayFacts` 攒出那一天走过的地方与景，再问事件与岔口各一遍；方向直接取 `directionsFor` 那份按天的账（它本来就是精确的）。**为什么不能偷懒从动作推景**：`SCENES[v][act]` 是一串景（改文件就有 spell / talisman / deed / map / ruin / frost 六个），`sceneOf` 还躲「最近几行说过的」与「开头撞物件的」——**景推不出来**，只有跑同一台机器，「整年的账」才不会跟屏幕上那句话打架。

**九件，顺序即优先级：**

| id | 条件 | 收束那一句（带名字） |
|---|---|---|
| `thin-year` | 那一年干过 30 天以内 | 这一年他没待多久，塔里恩后来又回来了。 |
| `kept-at-it` | 撞过 24 回以上 | 这一年就这么过去了，塔里恩还在镇上。 |
| `underground` | 走过矿洞，且撞过 12 回以上 | 这一年塌过几回，塔里恩都从底下上来了。 |
| `paid-off` | 交出过 10 样东西 | 一年下来，塔里恩手里总算攒住了几样东西。 |
| `held-the-line` | 收尾的那几条路（`hold`/`seal`/`cross`）占一半 | 这一年的事都收了尾，塔里恩没留下什么没办的。 |
| `walked-away` | 绕道的那两条路（`leave`/`back`）占一半 | 这一年他绕了不少道，塔里恩还是回到了那间屋子。 |
| `on-the-road` | 涉险的日子占四成 | 这一年他一直在走，塔里恩把北边那几条道都认熟了。 |
| `steady` | 攒盘缠与过日子占六成 | 这一年过得安稳，塔里恩把日子过成了老样子。 |
| `quiet-year` | **兜底，不带条件** | 这一年没什么可说的，塔里恩照旧坐在灯下。 |

每一件三句说法（`lines`，挑一句说），末尾一句 `close` 收束。

**第七台机器 `fateOf(facts, fates, ctx)`** 的判法与 `momentOf` 同一套：按顺序找第一件**每一项都中**的，一件都没轮到就取**最后那件不带条件的**。项语言在它这一层多认三个（判法见 `../rules.js` 的 `fateHit`）：

- `{ when: 'days', lte: 30 }`——那一年干过多少天；
- `{ when: 'direction', has: ['risk'], share: 40 }`——那一年落在这个方向的日子占四成以上；
- `{ when: 'roads', has: ['hold','seal','cross'], share: 50 }`——那一年走过的岔口里一半以上是这几条。

`share` 省掉就是「有这么一天就行」。**`momentHit` 一个字没动**：归宿这一层自己一个 `fateHit`，因为 `direction` 在别处读的是「一条记录上的一个字符串」，在这里读的是**一年的分布**。

**呈现**：那一段接在整行的最下面，上面一条虚线（`.gf-fate`）：先一句正字（`.gf-fate-line`，跟别处同一台阶），再一句**压暗一档**的收束（`.gf-fate-close`）。**收束那一句带他的名字**——所以名字现在全篇出现**两处**：开头那一段序曲的第一句，与每一卷年卷末尾那句收束。

   模板），改 `id`/`name`/`voice`/`label`，
   写 `actionLines`/`words`/`life`；想把**每一件事**都换成自己的说法，就再写一份
   `shards`——键照抄世界包 `scenes` 里那些 `key`，每条给 `{ w, lead, tail, more, paid, hurt, again }`。
   没写的键会退回动作级那句 `actionLines`（不会串到别的说法的句子里去）。
   多一个世界的（`kind: 'world'`）就照 `adventure` 那份来，连 `scenes`/`props`/`cast`/`rules` 一起给；
   **最薄的世界包**照 `.parked/ferry-voice/index.js` 那份来：每动作只给一个场景、几件道具、几条世界句，
   地理可以整块不给（不给就沿用默认世界那张图），`rules` 也可以不给（不打架）；
2. `src/packs/index.js` 里 import 进来、加进 `PACKS`（**顺序就是「故事风格」那张清单里的次序**）；
   `listPacks()` 自己会算出 `narrates`，不用手填；
3. `node scripts/packs.mjs` 过校验；`node scripts/verify-packs.mjs`（只对 `adventure` 有效，
   新包还没有对应的活对象，跳过它那块）；`node scripts/smoke.mjs`（「说法清单」那一节是从注册表推的，
   新包进去不用改断言）；
4. 想在界面上先挂个「付费·预览」的锁，就把 `free` 设成 `false`；只是想先把名字摆上去
   （内容还没写），就把 `soon` 设成 `true`——列在清单里、点一下摊开它自己那一句、点了不换说法，
   悬停浮出的也是那一句（**没有「还没写好」这种字样**，用户 m06529 第 2 条去掉的）。

## 校验

```bash
node scripts/packs.mjs          # 二十二条规矩，全过 exit 0
node scripts/packs.mjs --show   # 顺带打印违规样本
```

压的规矩：R1 没有阿拉伯数字 · R2 没有现代词 · R3 片段（`lead`/`tail`/`more`/`paid`/`hurt`/`again`）
不带句号 · R4 完整句带句号（含 `tagline`）· R5 生活句里没有行当词 · R6 活计句里没有起居词 ·
R7 一句话里同一件物件不提两次 · R8 没有 ！？ 与引号 · R9 结构（动作/词表/场景/四档结局/池内无重复/道具是 `[词, 键]`；
讲述者包的 `shards` 键对着**所有世界包**的场景键并集判——它自己不长 `scenes`）·
R10 世界的规矩读得懂（`when` 认不认识、时段/桶/概率写没写错——它引用的动作名不按文风审）·
R11 地理成套（`map` 与 `places` 要么都给要么都不给；`view` 是四个数；每个地点 `id` 对得上键、
`door` 是 `[x, y]`、至少一个名字、点落在取景框里；`actionPlace` 指到的地方都得存在；
必须有 `places.home`；`theme` 必须是 `THEMES` 里真有的 id）·
**R12 高光事件写全了**（`moments` 每件 `id` 唯一、`when` 非空且项名/时段/阈值合法、`steps` 至少两句
且都是字符串、`close` 是一句非空；条件里点到的场景名要在 `scenes` 里真存在、地名要在 `places` 里真存在；
经过与收束也进池内重复检查。**岔口**也归它管：写了 `choice` 就得正好两条路、每条要 `id`（件内不重）
与 `label`、`lines` 至少两句、**最后一条不许有条件**而非最后一条必须有条件，条件项按同一套判法查）。
**读不懂的条件比松的条件更危险**：它会静默地一件都不发生，
而屏幕上看起来跟「这天本来就没大事」一模一样。
**R13 一天的头尾与那顿饭写全了**（`dayFrame` 三样 `open`/`close`/`meal` 都在、六档钟点与六顿饭的名字
逐个对、多出来的键报「不认识的钟点 / 饭」；`meal` 那三桶也进 R5，`open`/`close` 进 R6）。
**R14 交锋写全了**（`clash` 的键必须落在场景表里、每键 `{hold, cost}` 各至少两句、只认这两拍、
**有 `shards` 的场景必须有交锋**——键与 `shards` 一一对应，对手与场地才必定合得上）。
**R15 序曲写全了**（`origin.name` 非空、`lines` 至少四句、**第一句里必须带名字**、名字只许出现在
**这两处**——`origin.lines` 的第一句与每一件 `fate[*].close`——别处再出现就报错；扫的时候跳过 `map`
那一支，那张图上的地名不是他；第五十四版起放宽过一次，归宿那句收束也要带名字）。
**R16 方向与比例写全了**（`directions` 四样 `id`/`label`/`cap`/`lines` 都在、`cap` 在 1–100、
兜底**正好一个**且 `cap` 是 100 且**不许带条件**、非兜底**必须有条件**、抬头至少三句；
兜底还得排在最后——顺序就是优先级）。
**R17 归宿写全了**（`fate` 每件 `id` 唯一、`when` 非空且项名/阈值合法、**不带条件的那件正好一个
且排最后**、非兜底必须有条件、`lines` 至少三句、`close` 非空；`direction`/`roads` 要有 `has`（或 `is`）
且 `share` 在 1–100；条件里点到的方向 id / 岔口 id / 场景键 / 地名都要真存在；说法与收束也进池内重复检查）。
**R18 命运抉择有份量**（`checkChoices`：摆了岔口的事件 `weight` 必须 ≥ 2；每条路的 `cost` 得是一句
句号收尾、去掉标点后至少 8 个字的完整话——不许空、不许零代价；每条路的 `marks` 是 1–2 样且在
`MARK_NAMES`（伤 / 账 / 名声 / 得着 / 知道 / 丢掉）里；**两条路留下的痕迹排序后不许一模一样**
——两条路得真不一样）。份量本身（`weight` 是 1–3 的整数）归 R12 判。
**R19 痕迹池不薄**（`checkMarks`：六个痕迹一个不许少、也不许多；每样都得有 `echo`/`life`/`world`
三池；`echo` 至少 4 句、另两池各至少 2 句——池子太薄，同一天里会撞回同一句）。
**R20 战斗写全了**（`checkFights`：`foes` 至少 3 个、`id` 唯一、`label` 非空、四池
`meet`/`way`/`trade`/`end` 各至少 3 句、**兜底对手（不带 `when`）正好一个且排最后**；
`tiers` 至少 2 档、`trade` 是 1–3 的整数、`way`/`turn` 是布尔、**兜底档位排最后**；
`turns` 与 `report` 各至少 3 句，且 **`report` 每一句都必须带 `{n}`**——那是日卷末尾的战报，
`{n}` 换成汉字数字；另对一眼条件里的场景键在不在场景表里）。
**R21 当日计划写全了**（`checkJourney`：`stations` 至少 8 站、`id` 唯一、`label` 与 `seal` 非空、
**兜底（不带 `when`）正好一个且必须在最前面**——它是路线的起点，不是收尾；`lossAt` 是两个递增整数、
落在 2 到站数之间；`losses.early`/`mid`/`late` 各至少 2 句；`plans.plan` 至少 3 句且**每一句都必须带
`{n}` `{place}` `{seal}`** 三个占位符；`plans.season` 四季各至少 2 句；另对一眼条件里的场景键在不在
场景表里、地名在不在 `places` 里）。
**R22 命运写全了**（`checkForks`：`forks` 每件 `id` 唯一、`weight` 是 ≥ 3 的整数、`when` 非空且项名/时段/
阈值合法、`look` 一到两句、**正好两条路**、每件**正好一条 `main`**（`kind` 只认 `main`/`branch`）、
**每条路都不许有 `cost`**（代价不可知——`road.cost !== undefined` 就报错）、每条路 `look` 一到两句、
每种结果 `beats` 至少四句、`marks` 至多两样且在 `MARK_NAMES` 里、**`then.die` 只许在 `branch` 上、
每种路至多一个、而且那条结果不许留痕迹**（死了就没有下文）、`then.back` 只许在 `branch` 上、
`then.tier` 只认 2 或 3、**每条路的兜底（不带 `when`）正好一个且排最后**；另对一眼条件里点到的
场景键 / 地名在不在表里）。
`map.svg`/`map.css` **不按文风审**（那里面全是数字与十六进制颜色）。

R3/R4 判的是**池子里的每一条**：`packs.mjs` 会把带下标的路径段（`tail[0]`）剥成字段名再判
（2026-10-05 之前这一步漏了，等于对数组元素一条都没生效）。

## 付费挂点

- 锁定＝`free: false`。`listPacks()` 里看得见（界面可以显示「付费·预览」），`setPack` 切不过去。
- **收款不归这个插件管**：插件市场（dshmarket / awesome-dsh-plugin.com）只是分发索引、没有结算。
  真收钱要自己接第三方（爱发电 / 面包多 / Lemon Squeezy……），拿到授权后把 id 传给 `isUnlocked`。
- 现在的 `isUnlocked(id, unlocked)` 是个桩：`unlocked` 从哪来（许可证文件？激活码换签名的 cookie？）
  以后定，接口先留着。
