# 收起来的东西

这里放**从产品里摘下来、但没舍得删**的整块内容。摘下来的东西**不参与构建**
（`scripts/build-client.mjs` 只摊平 `src/client.js` 真的 import 到的东西），
所以它们既不会进 `lib/client.js`，也不会被 `scripts/packs.mjs` 校验到。

## ledger-voice（原 `src/packs/ledger/`）

第二套说法「案牍」：26 个场景 × 开头4 / 收尾4 / 加码3 / 给钱3 / 挨打2 / 再说一次2
＝ 468 条片段 + 26 个标签词（包里一共 560 条字符串），另外还有 6 句动作兜底、词表、
30 条生活句。

**为什么收起来**：2026-10-05 用户看完面板上「谁在讲 · 案牍 · 冒险」之后裁决——
「我们只需要一个作为默认即可了！那么去掉案牍，我们只保留冒险，并且前面的『谁在讲』
改为『故事风格』。」同一份记录不需要两套口吻，故事风格留给出**世界**的包
（仙侠、规则怪谈那种）来分。

**怎么放回来**（两步，都在 `src/packs/index.js`）：

1. 把这个目录挪回 `src/packs/ledger/`；
2. 加回 `import { ledger } from './ledger/index.js'`，并把它写进 `PACKS`。

界面那边不用改：**「故事风格」那行字是从 `VOICES` 里长出来的**——包里多一套说法，
那行自动多一个按钮（只有一套时它显示成一个不可点的名字）。
`scripts/smoke.mjs`、`.tmp-acp/verify-packs.mjs`、`scripts/look.mjs`（`GF_VOICE`）
与 `preview.html` 里那些针对案牍的断言在收起来的那一轮一并删掉了，放回来时要补。

## ferry-voice（原 `src/packs/ferry/`）

第二个世界包「夜航船」，说法叫「船家」：221 条字符串（生活句 13）——每动作只有一个
场景、六条拼句池、三处熟人、十件道具、十四条世界句、四句家里话，外加七处河上地名
（渡口酒棚 / 镖局帐房 / 歇脚的船篷 / 河市 / 水文楼 / 抄单棚 / 船坞）、`theme: 'classics'`、
封面一个字「舟」、不给 `rules`。它当初是**第 4 步那件事的证据**：证明「换个包真的会
换一整套」。

**为什么收起来**：2026-10-06 晚用户看完那张只有一项的清单，说「**新的风格不应该是所谓
船家，去掉所有船家的内容**」，同一句里又定了三套预留的名字（规则怪谈 / 宫斗心计 /
谍战潜伏）。他要的是**风格**（体裁），而船家是**世界**的叫法——而且它的地理与主题在
入口从书架搬进「故事风格」之后本来就闲置了（界面里没有换世界的地方）。

**怎么放回来**（三步）：

1. 把这个目录挪回 `src/packs/ferry/`；
2. `src/packs/index.js` 里加回 `import { ferry } from './ferry/index.js'`，并把它写进
   `PACKS`（**放哪儿决定它在清单里的次序**）；
3. 修一下 `index.js` 顶部的 import——收起来那一轮它已经改过一次（`../../map-data.js`
   → `../../map/world.js`），挪回 `src/packs/ferry/` 之后 `../../map/world.js` 正好又是
   对的了，所以这一步通常不用动。

界面那边不用改：清单是从注册表长出来的（判据 `listPacks()` 的 `narrates`，按 `voice`
去重），包里多一套说法，清单里自己就多一项。
`scripts/smoke.mjs` 里针对船家的那几条（说法表、清单节、kept 那节、locked 那节的底包）
在收起来那一轮改成了「对着注册表推」，放回来时不用补；但 `.tmp-acp/check-ferry.mjs`
是删掉的，要重新写。
