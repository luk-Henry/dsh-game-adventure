# 一天的骨架（按新世界观与人设重写）

> 用户 m14933（逐字）：「这个世界病了或者有什么东西异常了，于是他有一个终极任务也是人生任务，
> 一个终局，这一路上，他要生活、要调查、要寻找、要保护，也要一路杀过去。
> **这样他才能走完整个大陆，到处奔波。**」
>
> **这一版把默认改掉了**：以前默认他**在镇上**、偶尔出门；现在默认他**在路上**、偶尔歇脚。

---

## 一、一天的边界：从他醒来，到他睡下

- **醒来**：第一格往前推约一个半钟头（下限四点）。**不在同一张床上**——可能在店里、在野地、
  在别人的屋檐下、在马上。
- **睡下**：最后一格往后推，长短**看最后一格落在哪个时段**（这就是「看情况」在实现上的意思）。
- **醒来前与睡下后**那两段由**习惯**补（见第四节），不是虚空，也不是观察来的。
- **一天从他醒来算到他睡下**；跨过午夜也算同一天。

---

## 二、两种日子：**赶路的日子**（默认）与**歇脚的日子**

> 用户 m14933：「**到处奔波。**」⇒ 赶路是常态，歇脚是例外。

| | **赶路的日子**（默认） | **歇脚的日子** |
|---|---|---|
| 什么时候 | 你的动作里有跑命令、查资料、派了活，或坐得极短、极散 | 你的动作集中在改文件、翻文件、聊了聊 |
| 他在干什么 | 走、问、找、挡、打、夜里守 | 描咒、誊抄、画图、修机关、把册子摊开对字 |
| 在哪 | **路上**：荒路、林子、山道、船上、别人家的屋檐下、野地那六处 | 旅店、书斋、公会的火边、借住的屋子、碑下小屋 |
| 一天的样子 | 碎、险、走一段停一段 | 长、稳、一件事做到黑 |
| 危险 | **拦路的人、压边的兽人、死了的东西、塌方、火** | 赶工、欠账、被人盯上 |

**一天里几乎总有一段在路上**（哪怕只是从这村走到那村）；
**歇脚的日子也照样出事**（半夜拍门、集上抢货、作坊起火）。

### 2.1 一场战斗怎么接进来（**第二期多一台机器**）

```
状态（在哪 / 在做什么 / 撞了几次 / 坐了多久 / 深夜没有 / 身上带着什么 / 病征多重）
   ↓
fightOf(state) —— 回答：这一段有没有一场仗、对手是谁、打几拍、怎么收的
   ↓
那一行下面接一场（遭遇 → 试探 → 交手 → 转折 → 收束），或日卷末尾一句战报
```

- **触发**：这一行落进「挨打」那一档（它本来就已经按真实的撞墙次数与危险算过了）。
- **对手**由**地点**定：荒路→拦路的人、夜哨→兽人、霜原→雪狼、**封印松的地方→死了的东西**。
- **档位**由**撞墙次数与坐了多久**定；深夜、病征重、被人围 ⇒ 大档（**可以变成命运**）。
- **日卷那一行末尾报一句战果**——**这是折叠之后照样看得见战斗的关键**。

## 三、七个时段（骨架的主干）

粒度是**五分钟**：每五分钟他有一个状态；同一件事连着做就一直做下去，直到被打断。

| 时段 | 钟点 | 赶路的日子 | 歇脚的日子 |
|---|---|---|---|
| **天亮前** | 0–6 | 赶早路；或守夜；或在外头刚醒 | 还在灯下；或刚起身 |
| **早晨** | 6–11 | 收拾、灌满水、看一眼天、上路 | 吃饭 → 上工 |
| **午前** | 9–12 | 走第一段路；到地方；**问路** | 手上那件正活 |
| **中午** | 11–14 | 路上吃口冷的；或到了地方顾不上吃 | 吃饭（**最要紧的一顿**） |
| **午后** | 14–18 | 办事、找、量、**挡**、往回走 | 正活 / 跑一趟（送、买、访人） |
| **傍晚** | 17–20 | 找落脚的地方；赶不上就在外头歇 | 吃饭、收尾、归置 |
| **夜里** | 20–24 | **最危险的一段**；或留宿在外 | 灯下接着做 |

**定场与收尾**：一天的**第一格**说一句定场（这一天的头起在哪儿），**最后一格**说一句收尾。
**今天还没过完就不说收尾**——`partial` 那条规矩保留。

## 四、当日计划：他今天打算做什么

### 4.1 计划是什么

一天开始，他手上有 **2–4 件**。**计划一旦定下，一整天不再变**——
变了就说明被打断了（第五节那张表），而不是计划本身在飘。

### 4.2 计划从哪儿挑

1. **册子上的下一站**（常驻第一位）——赶路的日子，这一件占大半。
2. **这一段路上的事**：要问的人、要找的东西、要护的人。
3. **常活**（挣钱）：护一趟路、抄一页、修一件机关。
4. **世界当前状态**：季节、路通不通、集日、哪一片病征重了。
5. **今天的信号**（你今天的动作）——**只决定他做成了没有，不决定他打算做什么**。

### 4.3 路有季节性（**新加，也是这一版的「钟」**）

**这是「一年那条钟」，而且是日历算出来的，不需要跨天记忆**：

- **北边的路只有夏秋能走**（巨人之脊、北境霜堡，入冬就封）。
- **海路要看季风**（灰港、珊瑚海国，冬天不出海）。
- **荒路冬天不能走**（裂牙荒原、龙骨荒漠）。
- **逢五开集**：买东西、打听消息、找人。

⇒ **册子上的顺序，一半是季节替他定的**：
入冬前必须把北边那两处走完，不然要等明年——**而明年碑更旧、东西更多。**

## 五、计划怎么被打断

| 你的信号 | 在故事里是什么 |
|---|---|
| 一口气坐了 2 小时以上 | **他陷进去了**：这一天就耗在这一件上 |
| 反复出错（撞墙多） | **他碰了壁**：返工、把东西弄坏、**打了一场、挨了一下** |
| 交出了东西 | **那件事成了**：交出去、换了钱、落了名声 |
| 只坐了一小会儿 | **他刚坐下就被叫走**，或只是回来取件东西 |
| 深夜还在做 | **他这一天没过完**（守夜、赶路、追东西） |
| 什么都没干 | **他今天在别处**——不在桌前，那也是他的一天 |

## 六、状态量（引擎要算的东西）

每个五分钟，他有一个状态。这些量**都是算出来的，不写盘**：

| 量 | 取值 | 从哪来 |
|---|---|---|
| `在哪` | **这一站在哪儿**（大陆上的地名 + 十三个旧地方 + 野地） | 计划 + 动作 + 时段 |
| `在做什么` | 六种活之一（动手 / 翻查 / 试 / 打听 / 支使 / 说话） | 你的动作 |
| `那件事做到哪一步` | 没动 / 做了一半 / 做成了 / 砸了 | 交付物 + 撞墙次数 |
| **`册子按了几个指印`** | 第几站（一到十一） | 计划 + 那件事的进度（**主线进度条**） |
| **`他身上少了什么`** | 没少 / 开始做梦 / 听不见南边的话 / …… | **每描一处少一分** |
| `身上带着什么` | 伤 / 账 / 名声 / 得着 / 知道 / 丢掉 | 命运走的那条路（**只活当天**） |
| **`这一段的仗`** | 没有 / 打上了（对手 + 几拍 + 收在哪） | 撞墙次数 + 地点 + 坐了多久 + 深夜（见《战斗》） |
| **`身上的拖累`** | 卷刃 / 符墨见底 / 旧伤犯了 | 前几场仗留下的（**只活当天**） |
| `今天打算干什么` | 2–4 件 | 第四节 |
| `钟点与路` | 七个时段 + 季节 + 路通不通 | 记录的时刻 + 日历 |

**一句话**：`在哪` + `在做什么` + `什么处境` + `什么钟点` = 一个**槽位**；
每个槽位底下有 2–4 条备用说法，**散列只在同义说法之间挑**。
**散列不再决定发生什么。**

## 七、命运（**麦基式的两难**）

### 7.1 什么叫命运

> 用户 m14810 第 5 条：「让用户可以做出选择的内容，就叫做『命运』，这件事是一件大事。」

四条判据（缺一不可）：

1. 逼他在**两个都要失去一点**的东西之间选（**不许有正确答案**）。
2. **推进或毁掉**「册子 · 某个人 · 他自己」里的某一件。
3. 代价在他选之前**看得见**。
4. **留下痕迹**。

**总两难**：**描，还是走。** 每个命运都是它的小版本，代价一次比一次高。

### 7.2 一天最多一个

多的不摆——**命运一多就不叫大事了**。

### 7.3 用户不选，故事就停在这儿

- **摆出来就停在这一格**：后面的行不往下写。
- 门上那枚记号**一直亮**。
- **不自动替他选**——旧的「你没做抉择，他自己走了一条」**作废**。
- 抬头从「命运抉择」改成「**命运**」。

### 7.4 跨天怎么办（方案 A 的直接后果）

未选的命运**只活今天**：一天过完还没选，**这一天就停在那儿、没有结尾**
（因为结尾还没发生）；第二天是新的一天，**不补记忆、不追认**。

## 八、弧光怎么走（一天一步）

| 段 | 走到哪儿 | 引擎要算出来的 |
|---|---|---|
| **描** | 界碑镇 → 河间城 → 银树书库 | 册子上的第一个指印；他还只会挡、只会退 |
| **起** | 铁砧山 → 北境霜堡 → 灰港 | 打斗里第一次起咒；**他丢过一样东西** |
| **守** | 东岸商盟 → 鸦林 → 龙骨荒漠 → 珊瑚海国 → 灰烬之地 | 不再算回家的船钱；册子快按满了 |

**引擎不需要知道现在是哪一段**——它只要老实算出「册子按了几个指印」「他丢过什么」，弧光自己会显出来。

## 九、观察（这个插件到底在做什么）

1. **用户的记录是观察点**：面板上每一行＝我们在某一刻**看了一眼**他在干什么。
2. **看到什么由那一刻的状态决定**，不由散列决定 ⇒ **同一格看两遍是同一句话**。
3. **你的行为是外力**：决定这一天哪里被打断（第五节那张表），**不决定哪句话被挑中**。
4. **没被观察到的时段**由**习惯与计划**补足——吃饭、走路、睡下，都是他这一天真在过的部分。
5. **一条底线不变**：`records.json` 一个字都不动，折叠只改显示。

## 十、不写的东西

- 不写他心里怎么想（只说外面看得见的事）。
- 不写「时间跳过了」「与此同时」这种讲故事的腔调——**时间是连续的，他一直在过日子**。
- 不写他不在这个世界里的东西；不写现代词、阿拉伯数字、！？ 与引号。
- **不假装虚空叙事**：每一句都落在这本书里的某个时段、某个地方、某个处境上。

## 十一、这一本怎么变成代码（给第二期用的形状）

```
records（今天的记录）
   ↓ 观察点 + 外力
dayPlan（当日计划：2–4 件，一天不变；第一位是册子上的下一站）
   ↓ 铺进七个时段（赶路的日子 / 歇脚的日子）
stateAt(t)（每五分钟一个状态：在哪 / 在做什么 / 哪一步 / 册子到第几站 / 少了什么 / 带着什么 / 钟点与路）
   ↓ 槽位 + fightOf(state)
slot（路上·打听·带伤·夜里·赶路） ＋ 这一段的仗（对手 / 几拍 / 收在哪）
   ↓ 2–4 条备用说法里挑一条
那一行（＋ 高光事件 / 痕迹回声 / **一场仗**）
```

- **要换的只有最后一跳**：现在是「从平权池里按散列挑」，以后是「从槽位名下挑同义的那几条」。
- **要新写的**：`dayPlan`、`stateAt`，以及**第十一台机器 `fightOf(state)`**。
- **要留的**：`dangerOf` / `outcomeOf` / `momentOf` / `choiceOf` / `fateOf` 那十台机器——
  它们算的正是「什么处境」；**`fightOf` 读它们算出来的危险与那件事的进度**。
- **要改的**：命运那一层——改成「**摆出来就停住**」，抬头改成「**命运**」。
