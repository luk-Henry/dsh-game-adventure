这是 src/client.js 的真实渲染（经 lib/client.js 打包后原样运行），喂的 是 2026-10-02 那台机器上真实回填出来的记录。
右下角那扇小木门是真的可以点的：移上去会浮出「门后」，点开是一张地图加一条见闻录。
地图是运行时画出来的（src/map/ 那五件是 .scratch/ 里那套 Python 渲染器的
等值移植，进面板只灌进一个 <g>）：一整块大陆、东北三座离岛、一个内海、
三条山系（沿脊线排成一串，不是散落的三角）、九片林子（一片林子一个整体）、三条河与三个湖、
十四片地表（九种颜色）；
四块地各有各的地表颜色（领地染色），没有国界、也没有分界线——分界靠笔法换了一种，说两遍反而把层次读断。
画布本身就是内容（VIEW 是 0 0 66 34，没有一圈要裁掉的空白），
上面是二十座城的记号与国名（一级国连名带徽记，二级国只留记号），右下一枚磁针式指南针（刻度圈加一根微微斜着的针，北半朱红；浅色墨画的，整枚都在画布里，天黑也不跟着暗）。
还有八处奇观——世界之树、两座浮岛、大法师塔、龙骸、水晶脉、符文石、污染之地，
每一处带一圈暖光晕与一圈虚线环，钉在已有地理上，不新开地。
地点按各自的文化画成小符号——人类的红瓦小屋加方堡、精灵的白塔林（青绿洋葱顶）、
矮人的山门要塞（一面峭壁加一道大拱）、兽人的圆顶大帐；另有草簇、冻原点、石纹、沙丘、冰裂这些地貌笔触
散在图上（世界图与细节版各按各的密度撒——细节版是 3×，所以草石沙冰都撒得密三倍）。世界图上不画农田，成片的犁田只在细节版那张地方图上。他本人不画出来，
只用一枚朱红记号钉在他此刻待的地方，旁边贴一个地名——这枚记号一直在图上，不许消失：
在城里就钉在那一座；出城那几件活（描残咒、送契书、下矿洞、拖法器、翻塔册、查夜哨）
各有自己的野地落点，名字都是地图上真有的地方（乱石岗、霜原、地下矿洞、河湾、废塔、夜哨），
连着几个钟头没有记录、他「出门了」的时候，钉在他的屋子；换地方的时候他是走过去的
（按两地的距离算，1.2–3.6 秒），不是「刷」地跳过去；地图和下面那几行字是左右对齐的。
地图分两级：全图里点一下就进细节版（不用滚轮——面板本身要滚动，滚轮会打架），
按住能拖，双击回全图（右下角一颗「全图」小按钮、Esc 也算），
右下角还留着一张 112×58 的小全图（一整幅世界图缩进去 ＋ 一个取景框 ＋ 一枚红点就是他，
只在细节版里露出来），点哪儿看哪儿；他走出视野时视野跟着他走。
细节版是同一套地方图（同一个坐标系，取景框 22 × 11.35，三倍线性分辨率；城墙、街道、广场、井、摊、
按种族画的地标（一级镇两处，第二处是望楼）、成片的犁田（一片田庄＝三块错着角的田＋两捆禾，
七道顺着长边的细犁沟；镇与镇之间的土路试过一版路网、当天就撤了——这张图上的山、树、房子都是立起来的物件，
平铺在地面的一根线会横着压过山体，看着像贴在山坡上，没有高度场就宁可不画）、
靠水镇子的木栈桥与渔船（桥根算到岸线、六块桥板两根桥桩；船是实心船身＋白帆＋红旗）、左上角一块题名框（写的是这一带的大名：有国家管着的地方写国家名，比如「河间王国」；
远海、无人荒原那些没有国家管着的地方写那一片的海名或地貌名，比如「断桥海」）；窗里出现的城一律按城画（一级国大、二级国小），
同一块地永远只有一种画法；每座城——包括他站的那座——都在自己城旁边挂上名字牌（比如「河间城」），
题名框写哪个国家由「窗心最近的那座城」定（离最近的城超过十个世界单位就算没人管，改写那一片的大名），那只影响牌子上写谁，不影响画出来的镇子）。
底下先垫世界图自己的三倍（借同一份 DOM，零成本、拖动时跟手），松手 30 毫秒才把地方图
画进来（一扇 2600～4100 个元素——2026-10-09 先把图里那三千多条线段并成了几条 <path>（4702 → 2847），
同一天又把四十块旧田换成一片片田庄，河间城 3766、古林之心 2614）——缓存里已经有的那一扇当场就画、一秒不等，
松手也不再换地面（原来松手那一帧先把位图关掉、把世界图那层露出来、再换取景框，整块重栅格化一遍）；拖的时候只挪便宜那层
（实测挪世界图那层 252 帧掉 1 帧、真挪地方图那层掉 21 帧），所以拖动中地方图真的不画
（不是压透明度：压着它照样每帧重画 5686 个元素）、世界图顶上来，记号、地名签、那盏灯跟地面
走同一个位移（不然地面在滑、记号钉在屏幕上不动，看着就是记号跟脚下的地对不上），松手才画新的那一扇。
取景框整扇必须落在世界图里——拖到面板外面也不会把底下那张全图露出来（不然屏幕上会叠着两张地图）。
拖动也不会选中地图上的字（那是浏览器自己的选中，用 user-select: none 关掉）。
拖的时候位置一帧只写一次（鼠标一秒能报上千次，屏幕一秒只要 60 次——攒到下一帧一起写），
并且整组换快速栅格化、把小全图那张也收起来（它里面又是一整份世界图），松手立刻恢复精细的那一套。
再往后一步：拖动的时候地面上顶上来一张预先烘好的位图——第一次进细节版之后趁空闲把整张世界图 3 倍烘成一张 1524×786 的 PNG，
拖动时露出来、把矢量那两层一起收起（烘不出来就一直走矢量，功能一样、只是慢）；那张图一上来，底下那两千多个元素
浏览器就不再为它干活了（把基础世界图也藏掉实测一模一样）。
画好之后它会在空闲时把周围八扇先建好（所以停一下再挪，多半是当场换）；
拖动期间只认一条路：手一停（24 毫秒没有新的鼠标位置）就把「松手多半会落的那一扇」先建上——手一直在动时一片都不建。
再往前两步：面板一上来，他所在那一扇就已经排进队列了（最可能被点的那一扇先建好）；
拖动里手一停 90 毫秒，也把那一扇先建上（原来这个门槛是 160 毫秒）。
记号、地名签、那盏灯浮在细节版上面，在屏幕上不变大小；跟着放大的只有地面
（他脚下那块地补一个 1/3 的反缩放，所以他脚下那块地永远压在他记号底下）。
那枚记号一直轻轻上下浮动——它原来是一跳一跳的（steps(4)，两秒半里只改四次值），
因为动画每帧改值会让浏览器每帧重画整张 5817 个形状的地图；这一版把灯、记号、地名签
整组搬进自己的一张 SVG（自己成一层，取景框跟地图永远同步），每帧只重画那一小层，
浮动改回光滑（同样的两秒窗口，主线程从 1909ms 降到 587ms），拖动地图时它们按停。
细节版那一份不用 SVG 模糊（一扇图里 93 道，一帧要 80 张离屏层），放大也拆成了
「内容钉在窗心上、画一扇才写一次 ＋ 每帧只挪一层空的 <g>」——
同一套探针扫下来，掉帧从 91 掉到 0（摘掉模糊逐像素比只差 1.98/255，看不出来）。
天黑的时候地图自己也暗下去，而且是提灯照地：罩子不再是一块盖满的矩形，
是以他为中心的一圈径向渐变——脚下透亮，到九个世界单位才暗到原来的程度，
半径随时辰收放（傍晚铺得开、深夜只剩脚下那一圈）；木框、记号、那盏灯都还亮着。
细节版那张地方图也走同一套光池——全图那圈与细节版那圈圆心都是他脚下那块地自己，
半径按 3 倍反补，所以两块地在屏幕上是同一片光；全图那圈的圆心固定在他脚下那块地、
只在换地方或换时辰时才写一次（值没变就不写属性）——那一处原来每帧重写，实测掉帧 10 → 0。
细节版田里那 98 条犁沟（.lf）也补上了——它们的样式一直住在没人灌的 LOCAL_CSS 里，
从画出来那天起一条都没显示过。
最上面就是地图，底下每块都带自己的标签：时间 / 位置 /
见闻录（你的日常 · 他的冒险）——不用点任何东西，一眼看完。
他此刻那句话就写在见闻录最新一行的右栏里（行首补一个「此刻」），不再单独占一行。
见闻录一行 = 一次坐下干活（中间停 45 分钟以上、或一段干满 2 小时就另起一行），
行首近两天写「今天 / 昨天 / 前天」；
左栏只用名词和数字（哪个动作各几次、动了哪几个文件、待了多久），句子全在右栏；
右栏那句话是片段拼出来的（同一天永远同一句，换一天才换），不花一个 token：
每个动作底下有 3–4 件不同的事（一共二十件：抄咒文 / 誊符纸 / 改契书 / 补地图 / 试法器 /
调机关 / 修炉子 / 翻卷轴 / 上架子 / 搬箱子 / 查册子 / 打听 / 问路 / 对说法 / 派同伴 / 分派路线 /
贴招条 / 闲聊 / 听人说 / 搭话），每件事有自己的开头和收尾；
同一件事有四档结局——那天交出了东西（去交活、拿几枚铜币）、那天撞过墙（工具报错过，
他就挨了两下）、做很多遍（一半是「成了」，一半是没成）、只做过一两次（不吹成几十遍）；
另外他那边还有一行更淡的生活（起得早、深夜还亮着窗、中间出去过一趟）——不是每行都有。
每一行都不一样：整条见闻录是按顺序拼的，每一行的开头避开用过的开场、物件避开最近三行，
连着三行都在同一件事上就让第二件事顶上来（位置也跟着换），同一句收尾在最近八行里不许重样；
次数只出现在约三分之一的行里（报的是事，不是账）；标签上就是这二十种叫法。
位置和句子对得上：他在他的屋子，说的就是屋里的事（吃饭、歇脚、收拾东西），
不会地图上标着他的屋子、句子还在讲野地里翻箱子；落盘也对齐到钟面的整五分。
左下角是主题那一组按钮，只换色板；说法（故事风格）不在这里换—— 改说法的地方在门后那扇窗里「此刻」那一行的右端：那儿写着当前那一套的名字 （现在叫奇幻冒险，底下压着一条虚线：这儿能翻），点它弹出清单， 清单顶上写着「换一种风格」，里面只列其余几套（现在讲得出话的只有奇幻冒险一套， 另外列着三套预留的名字——规则怪谈、宫斗心计、谍战潜伏：只有名字、还没写， 点了不换说法，鼠标停上去浮出的也是它自己那一句；名字底下那一句「它的核」默认收着、 点一下才摊开，一次只摊一个）， 鼠标移开一秒自己收。
地图、他在哪儿、你说的那件事，两种主题里一模一样。
